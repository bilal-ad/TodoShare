ToDo App – Web & Mobile

Fullstack ToDo-App bestehend aus:
- React Web Frontend
- Node.js / Express Backend
- React Native Mobile App (Expo)
- MongoDB
- Docker Setup

---

📁 Projektstruktur

- To-Do-App        → Web Frontend (React + Vite)
- To-Do-Backend    → Backend (Node.js, Express, MongoDB)
- To-Do-Mobile     → Mobile App (React Native, Expo)
- docker-compose.yml → Startet Backend & Web

---

▶️ Web & Backend starten (Docker)

docker compose up

Web
http://localhost:5173

---

▶️ Mobile (Expo) starten

cd To-Do-Mobile
npm install
npx expo start
